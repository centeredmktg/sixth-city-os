# Send Loop Implementation Plan

> **For agentic workers:** REQUIRED SUB-SKILL: Use superpowers:subagent-driven-development (recommended) or superpowers:executing-plans to implement this plan task-by-task. Steps use checkbox (`- [ ]`) syntax for tracking.

**Goal:** Let a Sixth City rep open a person from inside the console, edit the draft, send it from their own Gmail with the HubSpot BCC prefilled (so it auto-logs), and jump to the HubSpot record to enroll.

**Architecture:** Send is a Gmail *compose deep-link* with the portal's log-to-CRM address prefilled as BCC — no OAuth/token infra, human-in-the-loop, and BCC logging un-freezes the Scoreboard without the (ungranted) HubSpot email scope. Server exposes the BCC address + a per-record HubSpot deep-link; the compose URL is assembled client-side from the *edited* draft. Spec: `docs/superpowers/specs/2026-07-07-send-loop-design.md`.

**Tech Stack:** FastAPI + SQLAlchemy (engine), no-build React + Babel-standalone (`web/console`), pytest (hermetic — conftest forces `DRY_RUN=1`).

```python
# engine/modules/hubspot_links.py
"""Deterministic HubSpot record deep-links. Contact (0-1) preferred over company
(0-2); the company link is the always-available floor once an account is pushed."""
from __future__ import annotations


def record_url(portal_id: str, *, contact_id: str | None = None,
               company_id: str | None = None) -> str | None:
    base = f"https://app.hubspot.com/contacts/{portal_id}/record"
    if contact_id:
        return f"{base}/0-1/{contact_id}"
    if company_id:
        return f"{base}/0-2/{company_id}"
    return None
```
In `web/server.py` `/api/contacts`, add `hubspot_url` to each serialized contact. Use the contact's `hubspot_id` (Task 3) when present and the account's `hubspot_id` as the company fallback. Example (adapt to the existing serialization shape):

```javascript
// Pure — builds a Gmail compose deep-link from the (edited) draft. BCC omitted when null.
function gmailComposeUrl({ to, subject, body, bcc }) {
  const p = new URLSearchParams({ view: "cm", fs: "1", to: to || "", su: subject || "", body: body || "" });
  if (bcc) p.set("bcc", bcc);
  return "https://mail.google.com/mail/?" + p.toString();
}
```
