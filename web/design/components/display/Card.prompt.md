Surface container for grouped content — the workhorse layout primitive.

```jsx
<Card>Default white card</Card>
<Card tone="dark">Editorial dark panel</Card>
<Card tone="brand">Teal gradient highlight</Card>
<Card interactive elevation="md">Clickable, lifts on hover</Card>
```

Props: `tone` (default/dark/brand), `padded`, `elevation` (none/sm/md), `interactive`, `as`.
