Compact metric for dashboards — label, big value, optional trend.

```jsx
<Stat label="Overall score" value="4.6" unit="/5" delta="+0.4 vs last 360" deltaDir="up" />
<Stat label="Responses" value={9} delta={2} />
```

Props: `label`, `value`, `unit`, `delta` (number auto-colors), `deltaDir`, `inverse`.
